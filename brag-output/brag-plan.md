# Utu — brag plan (tone: polished)

**What it is:** Utu is a solar marketplace for Iraq. You list the appliances you run, it sizes a solar system for you, then you request quotes from verified companies.
**For whom:** Iraqi homes and businesses tired of relying on the grid and generators.
**What sets it apart:** No meter reading or bill needed. Sizing uses Baghdad sun hours and outage patterns. The result goes straight into a quote request.
**Most impressive claim:** five appliances in, a costed 6.9 kWp system out, with "Generator dependency 0%".
**Visual hook:** the product's own sunset palette (graphite, solar amber, coral) and its real appliance rows dropping in.
**Real UI shown:** calculator appliance rows, estimated-result cards, the three assessment tiers and the before/after energy mix. All are captured from the running app using its built-in "Load demo values" example.
**Share caption:** Tell Utu what you run. It sizes your solar system and finds the companies that can build it.

**Angle:** a quiet, confident walkthrough of the core flow (entry → key action → result) told in the app's own copy.

**Privacy:** the frames use the app's built-in demo data only. No real customers, companies or credentials appear (the backend was offline, so the company lists were empty and are not shown).

Transitions: soft. Each scene's content leaves first, then the next scene's content enters, so busy layouts never cross-fade into each other.

**Sound:** a warm A-major pad (A–F#m–D–E–A) that changes chord with each scene, gentle plucked eighths at 96 BPM, soft airy swells on transitions, quiet in-key chimes as cards land, and a long resolve on the logo.
